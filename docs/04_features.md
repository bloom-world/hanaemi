# 04. 機能仕様

ボード上の付箋、MTG メモ、カンプから読み取れる仕様をまとめる。「（案）」は議論段階で、確定していないもの。

## F-01 認証・アカウント

| 項目 | 仕様 |
|---|---|
| 登録方式 | ①メールアドレスとパスワード ②SNS 連携（Google / Apple） |
| パスワード | 英数字の組み合わせで 8 文字以上 |
| メール認証 | 仮登録後、認証リンクを付けた「hanaemi本登録のご案内」メールを送る。リンクを踏むと本登録が完了する |
| 同意 | 利用規約とプライバシーポリシーへの同意チェックが必須 |
| 自動ログイン | ログイン済みならログイン画面をスキップする |
| SNS の選定理由 | 対象の 30〜40 代を想定（付箋: 日本は Twitter、世界は Facebook / WhatsApp。参考リンクあり） |
| 実装メモ | 付箋「メールアドレスの認証は実装が大変。Google / Apple 連携の実装がラク」 |
| 退会 | すべてのデータを削除する |

### プロフィール項目
- 姓・名（漢字・ひらがな・カタカナのみ）
- 性別（男性 / 女性 / 無回答）
- 年代 または 生年月日（未確定）
- お住まいのエリア（都道府県を想定。例: 東京都）
- 職種（例: 会社員）
- 婚姻状態（例: 独身（未婚））
- 起床時間 / オフの時間 / 就寝時間（アラームと通知に使う）

## F-02 トレーナー（キャラクター）

- 4 人（フローラ、サクヤ、サザンカ、ロータス）から 1 人を選ぶ。設定から後で変更できる
- 声優のボイスでガイドする。セルフワークのスタートガイド、応援、アラームで使う
- ナビキャラは OFF にもできる（議論メモ）
- （案）最初に 4 人を見せるが、選べるのは 2 人。残りの 2 人は早起きできた回数に応じて 1 人ずつ解放する（初期の付箋。最新フローでは 4 人から選ぶ形）
- セルフワーク画面のテーマカラーを、選んだキャラクターの色に合わせる（付箋）
- キャラクターの詳細は [06_contents-and-design.md](06_contents-and-design.md) を参照

## F-03 トリニティ診断（Trinity Balance）

ユーザーの **体（Body）・心（Mind）・魂 / 精神（Spirit）** の状態を％で可視化する、このアプリの中核の指標。

| 項目 | 仕様 |
|---|---|
| 設問 | 体 → 心 → 精神の順。1〜5 の 5 段階で回答（1: 全くそう思わない 〜 5: とてもそう思う） |
| 設問数 | フロー図は各 5 問の計 15 問。カンプは 5 + 4 + 4 問。MTG メモには初回 25 問・24 問・最小 13 問の記述もあり、**未確定** |
| 途中終了 | 体の回答後、「心 / 精神」に進むか「ホーム画面へ」戻るかを選べる。マインドマップには「最低 1 つ答える」とある |
| 再診断 | 何度でもやり直せる。やり直すと円グラフをリセットする |
| 部分的な再診断 | 心だけ再診断したい場合も**体の設問から始める**（心・精神の設問が体と関連しているため。開発向けの付箋） |
| 結果表示 | 各領域を％で表示する（例: Body 50% / Mind 90% / Spirit 30%）。天気アイコンも添える |
| 推移 | セルフワークを続けると％が改善していく |
| セルフワークとの連動 | おすすめのセルフワークはトリニティの状態に連動させる。％の数字とセットで検討する |

### セルフワークが効く領域（ボード上のメモ）

| セルフワーク | 効く領域 |
|---|---|
| 瞑想 | 心、魂 |
| フィットネスダンス | 体 |
| ジャーナリング | 心、魂 |
| モーニングダイアリー | 心 |
| 断捨離 | 心 |
| ヨガ | 体、心 |

> 判定ロジック（設問の重み、％の算出方法、セルフワークによる改善幅）は、ボード上で定義されていない。8/20 の MTG で「アルゴリズム診断と設問の設計」がタスクとして挙がっている。

## F-04 今日の状態（Today's condition）

| 項目 | 仕様 |
|---|---|
| 入力 | 晴れ / 曇り / 雨 / 雷 の 4 択 |
| 頻度 | 1 日 1 回。日付が変わってから最初に起動したときにポップアップで表示する |
| データ | トリニティの％とは**別データ**として管理・表示する |
| 活用 | ログを取る。カレンダーで可視化する。曇りが何日も続いたらホームでアラートを出す |
| （案）係数 | トリニティとの掛け合わせ: ☀️×1 / ☁️×0.75 / ☔️×0.5 / ⚡️×0.25。移動平均を使う |
| （案）UI | スライダー式にして、前日の位置を表示しておく |
| （案）通知 | 登録時に取得した時間帯（起床・オフ・就寝）に合わせて push 通知し、状態を入力してもらう |

## F-05 体重・体温の記録

- 体重（kg）、体温（℃）を入力する。1 日に複数回保存でき、ログとして残す
- グラフには記録の平均値を表示する
- カレンダーの日付をタップすると入力できる。数値は日付をタップすると見える（WF 付箋）
- 生理周期: WF には Start / End の入力があるが、付箋で「生理周期をなくす。Apple Watch・Fitbit とデータ連携して月額制にする」とある（**未確定**）

## F-06 グラフ（ダッシュボード）

- 対象: 体重、体温、セルフワーク（瞑想・ヨガ・ジャーナリングの実施時間）
- 期間: 日 / 週 / 月 / 年
- 表現: 体重は棒グラフ、体温は折れ線。セルフワークはアイコンで重ねる
- サマリ: 期間内の平均（体重・体温）と、種目別の合計時間
- 単位の設定（kg, ℃, min）
- 詳細画面（掘り下げた先のページ）は未作成

## F-07 セルフワーク

### メニュー
瞑想 / ヨガ / ジャーナリング / モーニングダイアリー / 断捨離 / ワークアウト（フィットネスダンス）

- 内容は今後随時増やしていく
- 最初から用意するもの（付箋）: Yoga（動画）、Fitness Dance（旧 Zumba、動画）、Meditation（声優の音声と画像）、歌う瞑想（？、動画）
- アイコンはセルフワークの内容がある程度固まってから作る

### コース
- 時間: **3 分 / 5 分 / 10 分**（開発向け）。MTG メモでは 5 分・10 分の 2 パターン
- 瞑想: ボイス（女性 / 男性）を選べる。開発向けの付箋に「時間の設定や Voice 選択などは開発依存のため、エンジニアに要共有」とある
- ヨガ: よくあるゴールを 3〜5 個決め、それに紐づくコースを最大 10 個作る（WF メモ）
  - ゴールの候補: 集中力を高めたい / 心と身体のバランスを整えたい / シェイプアップ / 深い呼吸を実現したい / ポジティブになりたい / 心や身体の浄化 / 精神を安定させたい / 免疫力を高めたい / 一日の活動の効果を高めたい / 疲れやストレスを軽減したい

### 実行フロー
コース設定 → スタートガイド（トレーナーの声）→ 再生 → 評価（5 つ星、スキップ可）→ 達成・バッジ → レポート → 週の記録

- 中断（左上の ×）時は、別のコーチ / プログラムを提案するダイアログを出す
- レポートでは、トリニティの状態がどれだけ改善したかを％で示す
- 週の記録では、月〜日のうち実施した曜日にチェックを付ける
- （案）セルフワークの終了後に 3 問程度のアンケートを取る
- 人が全力で運動できる（負荷をかけられる）時間は 30〜40 秒。それに合わせて「あと◎秒」のようにしっかりインストラクトする（メモ）

### 提供方法（案）
動画コンテンツ（撮影・録画）、オンライン 1on1 レッスン、アニメーション

## F-08 バッジ・ごほうび

- セルフワークを達成するとバッジを獲得する（シングルスター、ダブルスター）
- 獲得条件やバッジの種類はボード上で定義されていない
- （案）早起きの回数に応じてトレーナーを解放する（F-02）

## F-09 アラーム・通知

| 項目 | 仕様 |
|---|---|
| アラームの種類 | 起床 / オフの時間 / 就寝。登録時に設定した時間で、それぞれ ON/OFF。任意の時刻のアラームも追加できる |
| ボイス | トレーナーが起こしてくれる。ON 時は（声優）「おはよう」、スヌーズ時は「早く起きよう！」 |
| マナーモード | 目覚ましアラームはマナーモードでも鳴らす。背景音や声優のガイド音はマナーモードでは鳴らさない（イヤホン接続時は鳴る） |
| アプリ内通知 | UI は未作成 |
| お知らせ一覧 | UI は未作成 |
| ステータス | 付箋「アラーム設定を追加する。UX 設計が必要。3/6 着手」 |

## F-10 サウンド・BGM

- 起動時のオープニングサウンド（起動音があるとなお良い）

- 今日の状態、体重・体温入力の画面でも BGM を流す（マインドマップ）
- トレーナー詳細で声優のボイスを流す
